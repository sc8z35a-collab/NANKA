# Role C — 操作 & UI (`src/ui/*`, `styles/ui.css`, branch `agent-C`)
## 必須
- `export function initUI(app, world)`
- カメラ: 島の中心を周回するオービット（1本指ドラッグ=回転, 2本指ピンチ=ズーム, 2本指ドラッグ=パン少し）、慣性、極角制限、距離制限、地面にめり込まない(`world.getHeightAt`)。OrbitControls を使っても自作でも可（タッチの手触り最優先）。
- アイドル時(8秒無操作)は自動でゆっくり周回。
- ランドマークのタップ: Raycaster で `world.landmarks[].object` を判定 → カメラを滑らかにフォーカス移動 → 紹介カード表示。`bus.emit('landmark:open',{id})`。
- 紹介カード: 画面右側 38% 幅、白すりガラス、角丸 24px、タイトル・説明・小ネタ・「とじる」。左側は3D が見える。safe-area 対応。
- HUD: 左上ロゴ「NANKA」、右上にランドマーク5つのチップ（タップでフォーカス）、下中央に操作ヒント（数秒でフェード）。
- 内容は `src/ui/content.js`（日本語、やさしい絵本調）。
- 横画面スマホ (例 915x412 / 844x390 / 1012x480 CSS px) で崩れないこと。文字は `clamp()`。
- ランドマーク位置上に浮かぶ小さな丸いピン（HTML オーバーレイ、毎フレーム投影）もあると良い。
